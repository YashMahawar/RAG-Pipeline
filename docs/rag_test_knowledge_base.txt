Acme Robotics Corp is dedicated to accelerating human potential through autonomous, intelligent mechanical solutions. Founded in 2024, our primary objective is the deployment of collaborative robots (cobots) in high-risk industrial environments, including deep-sea extraction, sub-zero logistics, and orbital maintenance.

### 2.1 The Titan-X Cobot (Model TX-900)
The Titan-X is our flagship heavy-lifting unit designed for manufacturing floors and assembly lines.
*   **Payload Capacity:** 450 kilograms at full arm extension.
*   **Power Supply:** Dual core Lithium-Sulfur battery matrices yielding up to 14 hours of continuous operational cycle.
*   **Sensors:** Equipped with quad-channel LiDAR, ultrasonic proximity arrays, and a 4K stereoscopic visual processing node.
*   **Cooling System:** Liquid nitrogen-infused closed-loop thermal radiator. Operating temperatures must stay between -40C and 115C.

### 2.2 The Vector-7 Drone (Model V7-Fly)
The Vector-7 is an autonomous quadcopter optimized for indoor warehouse inventory audits and thermal imaging surveys.
*   **Maximum Airspeed:** 45 kilometers per hour.
*   **Navigation System:** GPS-denied indoor localization using ultra-wideband (UWB) beacons.
*   **Payload Capacity:** 5 kilograms (optimized strictly for scanning equipment or lightweight package delivery).

### 3.2 Central API Gateway (Port 8443)
To communicate with any deployed Titan-X or Vector-7 unit, developers must authenticate via the Core Gateway using OAuth2 bearer tokens.

#### Endpoint: GET /api/v2/telemetry/status
*   **Description:** Retrieves real-time thermal, battery, and joint strain data from a targeted asset.

#### Endpoint: POST /api/v2/kinematics/override
*   **Description:** Instantly halts all active mechanical routines and triggers the physical hydraulic braking lock.
*   **Danger Level:** High. This endpoint bypasses standard deceleration queues.
*   **Required Parameter:** `"emergency_auth_key"` (Must be generated by a level-4 safety administrator).

# SECTION 4: STANDARD OPERATING PROCEDURES (SOP)

### SOP-401: Routine Battery Cell Calibration
To maximize the life cycle of the Lithium-Sulfur arrays in the Titan-X units, engineers must perform a deep calibration sweep every 90 days.
1.  Navigate to the central power terminal and isolate the asset using the mechanical breaker switch.
2.  Connect the diagnostic harness to the maintenance port situated underneath the primary chassis.
3.  Execute the script `/opt/acme/bin/calibrate_cells.sh --force --depth=100`.
4.  Do not disconnect the unit until the LED status indicator pulses solid green. If it flashes red, reference Error Code E-2104.

### SOP-402: Emergency Evacuation Protocol
In the event of an uncontained thermal runaway in the battery storage room (Room 404B):
1.  Sound the manual alarm located at the exit door.
2.  The automated fire suppression system will deploy Novec 1230 gas within 30 seconds. Evacuate immediately.
3.  Do not attempt to use water extinguishers on the Lithium-Sulfur matrices under any circumstances, as this will accelerate hydrogen gas production and cause explosive fracturing.

# SECTION 5: TROUBLESHOOTING & REPAIR CODES

### Error Code E-1002: LiDAR Occlusion Fault
*   **Symptom:** The robot ceases all forward movement and flashes an amber warning light.
*   **Root Cause:** The upper optical sensor array is blocked by debris, dust, or an opaque film.
*   **Resolution:** Power down the unit. Wipe the sensor array with an isopropyl alcohol wipe (99% purity). Inspect the outer casing for deep scratches. Restart the asset.

### Error Code E-2104: Calibration Matrix Mismatch
*   **Symptom:** Cell balance scores deviate by more than 1.5% during SOP-401 execution.
*   **Root Cause:** Micro-fractures inside the internal anode layers or degradation of the electrolyte gel.
*   **Resolution:** The affected battery bank must be decommissioned, safely extracted, and sent to the recycling repository. Replacing single cells within an unstable module is strictly prohibited.
